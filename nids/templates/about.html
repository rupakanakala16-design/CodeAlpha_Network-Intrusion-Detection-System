Network Intrusion Detection System

A full-stack demonstration of how a rule-based NIDS monitors traffic, flags suspicious patterns, and visualizes threats — built for classroom and portfolio use with a completely safe, self-contained simulated traffic engine.

Objective

Monitor network traffic and identify suspicious activity using configurable detection rules, then surface that activity through alerts, analytics, and logs — the same workflow a real security operations dashboard follows, minus any real scanning or attack traffic.

Features

Network traffic monitoring

Live simulated packet feed with search and filters.

Rule-based detection

Enable, edit, and author your own safe detection rules.

Security alerts

Investigate, filter, and resolve generated alerts.

Threat analytics

Five Chart.js visualizations of alert patterns.

System logs

Full audit trail of engine and analyst actions.

Live dashboard

3D radar visualization and real-time stat counters.

Technology

HTML5
CSS3
JavaScript
Bootstrap 5
Chart.js
Python Flask
SQLite
Snort / Suricata layer

Safe-Use Note

This project ships with a self-contained simulated traffic generator so it works fully offline with no special privileges. It never scans, exploits, or attacks real systems. The optional Snort/Suricata integration point in ids/detector.py is provided only as a documented extension for readers who already run their own IDS sensor.
